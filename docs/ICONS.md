# Icon map

Every icon a sim can draw with `D.icon(name, x, y, size)`. 905 icons: Font Awesome Free 7.3.1 (CC BY 4.0) plus hand-drawn extras. Generated by `scripts/build-icons.mjs`.

The AI bench builder doesn't read this whole list: `src/lib/icons.ts` searches the map (names, labels, Font Awesome's search terms and the aliases below) for the words in a request and shows the model only the best matches. People are drawn as stick figures with `D.person(...)`, and anything with no good icon becomes a labelled token, `D.token(label, ...)`.
